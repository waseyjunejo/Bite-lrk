# Bite Larkana

Bite Larkana is a restaurant inventory, sales, and procurement management dashboard built with React, Vite, and Express.

## Features
- Inventory tracking and stock movement
- Procurement slip logging and demand management
- Department analytics and comparison views
- Cloud sync support via Supabase
- Admin login and role switching

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

This project is structured and ready for local development.
